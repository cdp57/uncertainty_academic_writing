## Submit all eight judge jobs

```bash
cd ~/447_demo2
for script in scripts/eval_*.slurm; do
    sbatch "$script"
done
```

Each job array contains 4 question shards, up to 2 concurrent tasks per array. **There are 32 SLURM array tasks total.** Each task uses 4 answer baselines x 5 answer seeds = **20 judgments per question**, all generated by the *same model that produced the answers*. It is an expensive stage; if a task reaches the SLURM time limit, resubmit the SAME script. Judging resumes using saved per-answer CSV checkpoints. The script calculates exact-match accuracy and token F1 quickly before loading the judge model.

To test one very small GPU shard before committing more GPU time:

```bash
sbatch --array=0 scripts/eval_llama_1b_sciq.slurm --num-questions 8
```

When the full task is later launched, the metric shard file is overwritten with the full set, and the completed judge answers from the test are reused.

## Summarize after all 32 array tasks are complete

```bash
python summarize_evaluation.py --results-dir results
```

Results include overall (all five seed slots), per-seed, and first-sample summaries, plus mean/SD across the five seed-slot summary metrics.

## Metric definitions / critical limitations

- **Accuracy** = normalized exact match against **any** reference answer (correct = 1). It is *not* semantic accuracy. More than one reference may be available for QASPER.
- **Token F1** = word-level precision/recall F1 against the *best-matching* reference. For yes/no/unanswerable categories, incompatible labels score zero. This is not the complete official QASPER scoring (which also includes evidence F1).
- **Self-judge verdict** = model says `TRUE`/`FALSE` plus judge confidence 1–10. Same model weights and 4-bit quantization as generation. It receives the question, reconstructed support, and candidate answer **but never gold references**. It is not an independent gold accuracy metric.
- `judge_true_rate` is the fraction of valid judgments marked TRUE; `judge_agreement_with_exact_match` compares self-judge to the conservative exact-match proxy, not a validated semantic label.
- Missing gold references are excluded from accuracy/F1 denominators and counted in evaluability statistics; missing/unparseable answers score 0 if a reference exists.
- **All five** P(True) brainstormed answers are evaluated. The original P(True) *probability* was only calculated for the first sample and must not be misinterpreted as a score for all five.
- Support is **never written to result CSVs/XLSX**, but is reloaded and used in judge prompts. The QASPER context retrieval is reproduced from the same `experiment_core.flatten_questions` function; keep `--max-context-chars` consistent with answer generation (default: 12000).
- The answering models used temperature 0.7 and five independent seeds. Judge calls use deterministic greedy decoding, without additional judge-sampling seeds.
